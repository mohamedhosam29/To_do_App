# To-Do List

A simple to-do list app built with React.

## What it does

- Add tasks with a title and optional description
- Mark tasks as done or not done
- Delete tasks
- Search your tasks
- See quick stats (total, completed, remaining)
- Click a task to see its details
- Light/dark mode
- Everything saves in your browser, so your tasks stay after a refresh

## Built with

- React
- React Router
- React Bootstrap

## Running it locally

npm install

npm start

Then open http://localhost:3000

## Notes

Tasks and theme are stored in localStorage.
